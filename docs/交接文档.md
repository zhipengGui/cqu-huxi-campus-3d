## 4. 如何运行

```bash
# 方式一（推荐，用户已知道）：双击 D:\huxi-3d-map\start-server.bat
# 方式二：
cd /d D:\huxi-3d-map && npm run dev   # 打开 http://localhost:5188（必须用 localhost，127.0.0.1 连不上）
```

```bash
npm run build                # 类型检查 + 产线构建
py scripts/build_scene_data.py            # OSM 快照 → public/data/scene.json（改 override/管线后必须重跑）
py scripts/fetch_osm.py                   # 重新拉 OSM（一般永不需跑，快照已进 git）
blender.exe -b --python scripts/blender/build_priority.py -- --asset all # 8 栋双档 GLB、报告、可编辑 blend
blender.exe -b --python scripts/blender/build_gates.py                  # 三门 GLB 与 blend
node scripts/qa_browser.mjs                                          # 需已启动服务，Windows Chrome；输出 work/qa/
```

服务断了的排查：`netstat -ano | findstr :5188`。Vite 默认只绑 IPv6 `[::1]`，所以必须访问 `localhost` 而非 `127.0.0.1`（启动脚本已加 `--host`）。

## 5. 技术架构

```
OSM 快照(data/snapshots/*.json, 已进 git, 不再依赖在线接口)
   │ scripts/build_scene_data.py（纯标准库）
   ├─ 校界裁剪（边界=way 239537195，校外 building 无名字只做淡背景）
   ├─ 楼型分类(七类)/高度(标注>层数>面积估)/校门(北东南西 barrier 节点)
   ├─ 导航图(0.5m 网格节点+dedup 边)/体育馆地标自动挑选
   ▼ public/data/scene.json（前端唯一数据源）
   │ src/（Vite+TS+Three.js）
   ├─ sceneBuilder/facades/trees：窗带立面纹理图集、道路分级、绿地水面
   ├─ landmarks/navigation：GLB 加载与参数化回落、A* 巡路
   ├─ placesPanel/placesInfo：浏览面板、详情卡文案
   ├─ tourStops：20 站精选巡游清单 + 导览文案（新增，P2.4）
   ▼ Blender（build_priority.py / build_gates.py）→ public/models/*.glb（8 栋×2 档 + 3 门）
```

关键目录：`data/snapshots`(OSM 快照，进 git)、`data/height_overrides.json`(用户楼高校准表)、`public/models`(GLB)、`public/photos`(官网实拍)、`docs/`(架构备忘+本文件)。

## 8. 技术踩坑记录（前人血泪，新 agent 必读）

1. **Three.js ExtrudeGeometry 材质分组：0=顶底面、1=侧面**。写反=窗带全贴屋顶、墙面纯素色。
2. 通用楼 mesh 原点在世界原点（几何携带绝对坐标），定位要用 `userData.cx/cy`，别用 getWorldPosition。
3. **Blender extrude_polygon 三坑**：多边形绕向必须归一 CCW（否则顶面黑）；洞环零高度侧壁面必须删（黑斑）；凹多边形顶面要耳切三角化（`triangulate_ring`）。都已在 `scripts/blender/build_models.py` 修好，改脚本别回退。
4. Blender 场景里"绝对坐标网格"与"location 对象"混用时，recenter 会甩飞局部坐标网格（gym 拱顶曾消失）。
5. gym 地标自动挑选必须加 bbox 对角线约束（≤180m），否则挑中整个田径场区。
6. **picker.select() 不要触发 onSelect 回调**（曾无限递归栈溢出）；GLB 组要用 `traverse` 收集（children 不下钻，曾致图书馆从列表消失）。
7. 渲染循环有 60fps 帽（原 240fps 空转费 GPU 且影响 IAB 截图）。
8. **Agent 工作环境坑**：本机 shell 是 cmd.exe（无 tail/花括号展开/timeout 重定向）；**Bash 工具中文参数会乱码——中文一律写进 py 脚本文件再执行**；git 无全局身份，本仓库已配 `ZhipengGui / 331632287+zhipengGui@users.noreply.github.com`（历史已 filter-branch 重写）；Overpass API 对本机不可用（WAF 403/406）；IAB 浏览器截图在会话后期会劣化（新开标签可救一次，重要截图尽早做）；CSS2D 标签别用 Playwright 点击（每帧 transform 变化永不稳定），用 cua 坐标（坐标从 getBoundingClientRect 查）。
9. 服务要用 `start-server.bat`/`start` 独立进程启动——agent 会话的后台进程会随轮次被回收（用户已被断服困扰过）。
10. **`navigator` 变量名冲突**：`main.ts` 里有个局部变量 `let navigator: Navigator | null`（导航器实例，`Navigator` 是 `./navigation` 的类），它 **shadow 掉全局 DOM 的 `navigator`**。凡要用 `navigator.clipboard` / `navigator.deviceMemory` 等 DOM 能力，必须写 `window.navigator`，否则类型报错 + 潜在运行时空指针。同理注意别在 `applyQuality` 等导航器初始化前的逻辑里读它。
