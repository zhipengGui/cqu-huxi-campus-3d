# 重庆大学虎溪校区 3D 地图 · 架构备忘

- 立项：2026-10-13，架构经用户审核通过
- 目标：复刻 [gxu-campus-3d](https://github.com/wcqqq1214/gxu-campus-3d) 风格的虎溪校区可旋转三维地图
- 部署决策：**仅本地，不公开**（不上 GitHub 远端、不部署 Pages）；如需分享再议

## 技术栈

- 前端：Vite + TypeScript + Three.js（纯前端静态站点，无后端、无地图密钥）
- 数据：OpenStreetMap（ODbL，页面需署名 © OpenStreetMap 贡献者）
- 离线管线：Python 3.13 标准库（无第三方依赖）

## 核心架构（学 gxu：数据驱动，接口只碰一次）

```
OSM API/Overpass ──▶ data/snapshots/osm_snapshot_*.json（进 git，一次拉取永久使用）
                        │ scripts/build_scene_data.py
                        ▼
                 public/data/scene.json（局部米制坐标 + 楼栋属性）
                        │ src/main.ts + sceneBuilder.ts
                        ▼
                 Three.js 场景（ExtrudeGeometry 楼块 / 道路条带 / 水面绿地）
```

- 坐标：WGS84 → 以 bbox 中心 (106.295, 29.595) 为原点的局部米制坐标，X 东 / Y 北；
  前端映射 x=东、z=-北、y=高（sceneBuilder.ts 顶部有约定注释）
- 高度：OSM `height` 标签 > `building:levels`×3.3m > 按占地面积默认层数（≥5000㎡:5 层，
  ≥2000:4，≥800:3，其余 2）。人工校准走 `data/height_overrides.json`（M2 引入）

## 目录

```
public/data/       scene.json（管线产物）

docs/              本备忘
```

## 里程碑

- **M1 数据管线 + 可旋转白模**（2026-10-13 完成）：快照→管线→321 楼/531 路/14 水/128 绿地渲染，OrbitControls
- **M2 交互**（2026-10-13 完成）：Raycaster 点击信息卡 + hover 高亮（位移阈值区分点击/拖拽）、
  搜索（楼名湖名子串匹配 + 下拉建议）、无依赖自写 tween 镜头飞行、CSS2D 楼名/湖名标注（距离 LOD + 开关）、
  height_overrides 校准管线（byId/byName，闭环验证通过）
- **M3 视觉**（2026-10-13 完成）：PCFSoft 软阴影（2048 shadow map，正交范围 ±1700）、
  楼栋按 id 哈希做同色系微差异、程序化示意树 1120 株（绿地散植、避路避水、InstancedMesh 两批次）、
  昼/昏/夜三档光照预设（背景/雾/半球光/太阳/自发光联动，夜间阴影关闭）
- **M4 性能与适配**（2026-10-13 完成）：道路按主次合并成 2 个网格 + 树木实例化
  （合计 62 draw calls / 12 万三角形 / 桌面 240 FPS）、手机适配（紧凑 HUD、信息卡底部抽屉、
  触摸手势原生支持、pixelRatio 上限 2）
- M5+（可选，未启动）图书馆等标志楼 Blender 精模、自动巡游、分享视角链接

## 已知限制 / 风险

- Overpass 对本机出口 IP 406（WAF），取数走 OSM 官方主 API（api.openstreetmap.org）成功；
  快照已固化，后续不依赖接口
- 321 栋楼里仅 6 栋有标注高度、88 栋有名字 → 高度默认值为主，校准入口 data/height_overrides.json（机制已验证）
- OSM 无树点（natural=tree = 0）→ 已用程序化示意树补植（1120 株，非真实绿化图）
- relation/13986651 外环不闭合被跳过，待排查
- 校界未截取，bbox 边缘可能带入少量大学城周边要素（gxu 用校界裁剪，可选做）
- 前端踩坑记录：CSS2DObject 必须挂进场景图才会渲染；道路 ribbon 三角形绕向决定法线朝向；
  字符串楼 id（如 "123-2"）不能直接 Number() 做随机种子
